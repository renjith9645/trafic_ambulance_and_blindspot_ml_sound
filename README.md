# Traffic Ambulance and Blind Spot ML Sound

An intelligent traffic safety and driver assistance system that uses Machine Learning, Audio Processing, and Computer Vision to detect ambulance sirens, monitor vehicle blind spots, and provide real-time safety alerts.

The system continuously analyzes environmental sounds and sensor data to identify emergency vehicle sirens and potential blind spot hazards. When an ambulance is detected, the system alerts the driver to facilitate safer and faster emergency vehicle passage. Blind spot monitoring helps reduce accidents by detecting nearby vehicles and warning the driver through audio or visual notifications.

## Features

* Ambulance siren detection using Machine Learning
* Real-time environmental sound classification
* Blind spot vehicle detection
* Audio and visual safety alerts
* Low-latency real-time processing
* ESP32 and Raspberry Pi integration
* Camera and sensor support
* IoT-enabled monitoring
